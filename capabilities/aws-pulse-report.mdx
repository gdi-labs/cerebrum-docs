---
title: AWS Pulse Report
description: A daily-cadence operations report that audits an AWS account via read-only
  calls, synthesizes a Markdown summary, and posts a richly formatted version to Slack
  — end-to-end, with no human in the loop.
---

It's the first scenario built on the
[external-tools platform](/developers/components/external-tools-platform):
all twelve AWS calls and the Slack publish run through the tool
registry, not the workspace file tools.

## What it enables

- One-command (or scheduled) AWS audit: compute footprint, storage
  hygiene, IAM key/MFA gaps, network exposure, cost movers, RDS
  posture, and CloudTrail coverage — all in a single run.
- A consistent, narrated artifact (Markdown + Slack) that the team can
  read in 30 seconds instead of clicking through ten console tabs.
- Graceful degradation when Cost Explorer or Compute Optimizer aren't
  enabled on the account: those checks report as unavailable and the
  audit continues with the remaining signals.
- A blueprint for future ops scenarios (Incident Response, Lead
  Qualifier, Vendor Audit) that need the same connector pattern.

## How a run works

Three steps, in order: **collect** (the AWS tool loop), **synthesize**
(the narrated summary), and **publish** (the Slack post). The report
only fires on jobs that ask for it — it's off by default — and it's
cost-bounded: at most $2.50 and ten minutes per run.

## Setup

- The AWS account is read through the account's own read-only identity
  — no long-lived keys to manage.
- Slack needs a bot token plus a default channel, and the bot must be
  **invited to that channel**: for a private channel a non-member bot
  surfaces "channel not found", which reads like a bad channel id but
  is a membership problem.
- The same Slack app also serves inbound conversation
  ([Slack Conversation](/capabilities/slack-conversation)), which needs
  additional scopes. Adding scopes requires **reinstalling** the app —
  which rotates nothing here, but does mean a scope change for one
  feature briefly touches the token this one reads.
