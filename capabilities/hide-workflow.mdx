---
title: Hide Workflow
description: '## What it enables'
---

Workflows that are stuck (e.g. waiting on user input that will never
come) can be removed from the Agent Workbench job list with a single
click. The row's history is kept, so analytics, audit, and post-hoc
replay still see it; only the live job list filters it out. A hidden
workflow can be restored if needed.

This unblocks the common case where a workflow stuck awaiting user
input clogs the list and would otherwise need an operator to clear it
by hand.

## How to use it

- In the jobs list, open the **kebab menu** on a workflow row and
  confirm the prompt. The row disappears from the list immediately.
- If the workflow was selected, the detail panel clears instead of
  showing a hidden run.
- Deep links keep working: a hidden workflow's status page still
  resolves — it's just out of the list.
