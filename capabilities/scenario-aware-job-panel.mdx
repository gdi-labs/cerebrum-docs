## What it enables

- **Right-shaped output for every scenario.** Each scenario's final output now renders in a layout fitting its shape, instead of the code-build-shaped default.
- **Scenario-aware, end to end.** Jobs and per-prompt outputs carry which scenario produced them, so per-scenario touches — timeline labels, filters, list badges — can key off a proper label rather than being re-derived from run history.
- **Backwards-compatible.** Jobs created before this change still render correctly, and unknown or ad-hoc scenarios fall through to the existing Markdown renderer — no regression on older runs or future scenarios.

## What you'll see

Fire one job per scenario from the workflow composer:

- `quick_qa` → an answer card with a confidence pill and a source list.
- `document_writing` / `research_brief` / `security_review` → styled Markdown: headings, lists, tables.
- `code_build` → a Markdown summary, plus the LIVE block in the panel header when the run produced a production URL.
- A job created before this change → falls through to the familiar Markdown rendering.
